# Grafana Processing Progress Dashboard

`dashboards/processing-progress.json` monitors processing state by stage, model, dataset, and split type.

The dashboard expects a JSON array of state objects exported by `monitoring/scripts/export_processing_states.py` from stage 1 `state.json` and stage 2 `similarity_state.json` files:

```json
[
  {
    "dataset": "kaggle_train",
    "dataset_name": "kaggle_train",
    "model": "smollm2_360m",
    "model_id": "HuggingFaceTB/SmolLM2-360M",
    "experiment_name": "kaggle_train__smollm2_360m",
    "split": "HG",
    "stage": "logprobs",
    "last_id": 199,
    "processed_count": 200,
    "output_format": "parquet",
    "batch_count": 7,
    "output_path": "D:/Projects/master_diploma/text-detection-data/data/processed/kaggle_train__smollm2_360m/HG/data",
    "updated_at": "2026-07-12T12:00:00+00:00"
  }
]
```

Docker setup:

1. Create a local `.env` file with your external data directory:

```powershell
Copy-Item .env.example .env
```

Default example value:

```text
TEXT_DETECTION_DATA=D:/Projects/master_diploma/text-detection-data
```

2. Start Grafana and the progress state server:

```powershell
docker compose up -d
```

3. Open Grafana:

```text
http://localhost:3000
```

Default login is `admin` / `admin`.

4. Open the provisioned dashboard in the `Text Detection` folder.

The Docker setup also starts a small Python HTTP server at this browser URL:

```text
http://localhost:8000/processing-states.json
```

Grafana reads the same service through Docker networking:

```text
http://progress-states:8000/processing-states.json
```

That file is regenerated by `monitoring/scripts/export_processing_states.py` from `$TEXT_DETECTION_DATA/data/processed/**/state.json` and `$TEXT_DETECTION_DATA/data/processed/**/similarity_state.json` every 5 seconds.

Stage outputs are stored as zstd-compressed Parquet batches:

```text
$TEXT_DETECTION_DATA/data/processed/<dataset>__<model>/<split>/data/*.parquet
$TEXT_DETECTION_DATA/data/processed/<dataset>__<model>/<split>/token_similarities/*.parquet
```

Manual setup:

1. Install the Grafana Infinity datasource plugin: `yesoreyeram-infinity-datasource`.
2. Expose an aggregated `processing-states.json` file over HTTP, for example at `http://localhost:8000/processing-states.json`.
3. Import `monitoring/grafana/dashboards/processing-progress.json` into Grafana.
4. Set the dashboard variables to your Infinity datasource and state JSON URL.

The pipeline writes individual state files under `$TEXT_DETECTION_DATA/data/processed/<dataset>__<model>/<split>/`. Aggregate those files into one JSON array before Grafana reads them.
