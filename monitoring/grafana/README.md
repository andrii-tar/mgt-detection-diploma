# Grafana Processing Progress Dashboard

`dashboards/processing-progress.json` monitors processing state by model, dataset, and split type.

The dashboard expects a JSON array of state objects with the same fields written by `scripts/kaggle_process_pipeline.py` state files:

```json
[
  {
    "dataset": "kaggle_train",
    "dataset_name": "kaggle_train",
    "model": "smollm2_360m",
    "model_id": "HuggingFaceTB/SmolLM2-360M",
    "experiment_name": "kaggle_train__smollm2_360m",
    "split": "HW",
    "last_id": 199,
    "processed_count": 200,
    "updated_at": "2026-07-12T12:00:00+00:00"
  }
]
```

Docker setup:

1. Create a local `.env` file with your external data directory:

```powershell
Copy-Item .env.example .env
```

Default example value:

```text
TEXT_DETECTION_DATA=D:/Projects/master_diploma/text-detection-data
```

2. Start Grafana and the progress state server:

```powershell
docker compose up -d
```

3. Open Grafana:

```text
http://localhost:3000
```

Default login is `admin` / `admin`.

4. Open the provisioned dashboard in the `Text Detection` folder.

The Docker setup also starts a small Python HTTP server at this browser URL:

```text
http://localhost:8000/processing-states.json
```

Grafana reads the same service through Docker networking:

```text
http://progress-states:8000/processing-states.json
```

That file is regenerated by `monitoring/scripts/export_processing_states.py` from `$TEXT_DETECTION_DATA/data/processed/**/state.json` every 5 seconds.

Manual setup:

1. Install the Grafana Infinity datasource plugin: `yesoreyeram-infinity-datasource`.
2. Expose an aggregated `processing-states.json` file over HTTP, for example at `http://localhost:8000/processing-states.json`.
3. Import `monitoring/grafana/dashboards/processing-progress.json` into Grafana.
4. Set the dashboard variables to your Infinity datasource and state JSON URL.

The pipeline writes individual files under `$TEXT_DETECTION_DATA/data/processed/<dataset>__<model>/<split>/state.json`. Aggregate those files into one JSON array before Grafana reads them.
